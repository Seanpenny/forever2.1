# Forever Fit Website

A modern, responsive website for Forever Fit Gym - Your Ultimate Fitness Destination.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that works on all devices (mobile-optimized)
- **Modern UI**: Clean and professional design with smooth animations
- **Hero Section**: Eye-catching hero section with call-to-action
- **About Section**: Information about the gym and its features
- **Trainers Section**: Meet the team with detailed profiles
- **Programs Section**: Comprehensive fitness programs and services
- **Media Gallery**: Showcase of gym facilities and equipment
- **Events Feed**: Stay updated with latest events and news
- **Contact Form**: Easy-to-use contact form for inquiries
- **Smooth Navigation**: Smooth scrolling navigation between sections
- **Mobile Responsive**: All pages optimized for mobile browsers

## 🚀 Getting Started

### View Locally

Simply open `index.html` in your web browser, or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server
```

Then navigate to `http://localhost:8000` in your browser.

## 🎨 Sections

1. **Home**: Hero section with welcome message and call-to-action
2. **About**: Information about Forever Fit gym, trainers, equipment, and community
3. **Leaders & Founders**: Meet the leadership team
4. **Trainers**: Personal trainers and coaching staff
5. **Programs**: Comprehensive fitness programs (Hybrid Training, Running Club, Kids MMA, Sports Conditioning)
6. **Media**: Gallery showcasing gym facilities and equipment
7. **Events**: Events and news feed
8. **Contact**: Contact information and inquiry form
