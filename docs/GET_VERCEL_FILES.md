# How to Get Your Vercel Project Files

## Option 1: Clone from GitHub (Recommended)
If your Vercel project is connected to GitHub, the files should be in your GitHub repository:

```bash
git clone https://github.com/Seanpenny/forever_fit_website.git
```

## Option 2: Download from Vercel Dashboard
1. Go to https://vercel.com/dashboard
2. Click on your project "forever-fit-website"
3. Go to Settings → General
4. Scroll down to "Source" section
5. Click on your GitHub repository link
6. Clone or download from GitHub

## Option 3: Vercel CLI (If you have access)
```bash
npm i -g vercel
vercel pull
```

## Option 4: Export from Vercel (Limited)
Vercel doesn't provide direct file download, but you can:
1. Check your GitHub repository (if connected)
2. Use Vercel CLI to pull files
3. Check your local git repository
